# Changelog

## 0.1.0

- Initial release
- Parse OpenDRIVE XML from OMEGA PRIME MCAP recordings
- Render lane surfaces as color-coded triangle meshes
- Render lane boundaries as lines
- Render road markings
- Support for line, arc, spiral, poly3, paramPoly3 geometry types
- Elevation profile support
- Configurable panel settings (toggle layers, tessellation resolution)
- Static map caching (parse once, render for full trace duration)
